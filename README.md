# E-Commerce Backend REST API

A backend application for an e-commerce system built
using Java 17, Spring Boot, Hibernate, and MySQL.

## Project Overview

This project aims to provide REST APIs for managing
products, categories, users, shopping carts, and orders.

## Technology Stack

- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate
- Spring Security
- MySQL
- Maven
- Postman

## Planned Features

- Product management
- Category management
- User registration and login
- JWT authentication and authorization
- Shopping cart management
- Order management
- Input validation and exception handling
- API documentation

## Project Status

Currently under development.
